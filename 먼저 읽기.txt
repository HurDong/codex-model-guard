Codex Model Guard · Windows · 5.1.0

설치
1. ZIP을 폴더에 모두 압축 해제합니다. ZIP 안에서 직접 실행하지 마세요.
2. '설치.cmd'를 더블클릭합니다. 관리자 권한은 필요 없습니다.
3. 표시된 두 훅의 설명을 확인하고 설치·신뢰에 동의하면 Y를 입력합니다.
4. Codex에서 새 채팅을 열고 첫 질문을 보냅니다.
   1. ⭕ 맞습니다 → Ctrl+Enter: 현재 설정으로 시작
   2. ❌ 안 맞습니다 → Ctrl+Enter: 모델·추론 강도 선택 후 텍스트 원문 자동 전송

필수 환경
- Windows용 Codex 데스크톱 앱에 로그인되어 있어야 합니다. CLI만 있는 환경은 지원하지 않습니다.
- Codex를 먼저 한 번 실행해 주세요. 설치기는 Codex CLI, Node.js 20 이상, PowerShell 7 경로를 자동으로 찾습니다.
- 실행 파일을 찾지 못하면 Codex의 로컬 실행 환경 준비를 마친 뒤 다시 설치해 주세요. 설치기는 외부 파일을 다운로드하지 않습니다.
- 원래 동작 검증에 사용한 앱: 26.1013.4894.0 / CLI: 0.163.0-alpha.10.2
- 앱 내부 로컬 통신에 의존하므로 다른 버전에서는 새 채팅 한 번으로 호환성을 확인해 주세요.

설치 범위
- 현재 사용자의 Codex 홈(~/.codex 또는 CODEX_HOME)에만 설치합니다.
- MCP first_prompt_confirm 및 두 훅(SessionStart, UserPromptSubmit)만 등록합니다.
- 동의한 두 훅의 정확한 해시만 신뢰 처리합니다. 전체 훅 신뢰를 우회하거나 다른 훅을 신뢰 처리하지 않습니다.
- 기존 MCP, 다른 훅, 로그인, 모델 기본값, 권한 설정은 유지합니다.
- 기존 파일은 Codex 홈의 hooks/first-prompt-confirm-backups에 자동 백업합니다.
- 다시 설치해도 같은 훅이 중복 등록되지 않습니다.
- 설치기는 실행 중인 앱이나 다른 채팅을 종료하지 않습니다.
- Windows의 실행 정책을 변경하지 않습니다.

제한 및 문제 해결
- 자동 재전송은 텍스트 원문만 지원합니다. 첨부파일·이미지는 원래 메시지에서 보내 주세요.
- '맞습니다'로 진행하는 원래 요청은 기존 입력을 그대로 계속합니다.
- 확인 카드를 생략하는 권한 모드에서는 전송이 차단될 수 있습니다. 앱에서 확인 요청을 허용하는 모드를 선택해 주세요.
- 설치 직후 카드가 안 보이면 다른 작업이 끝난 뒤 Codex를 다시 실행하고 새 채팅에서 확인해 주세요.
- 회사 정책이 설치 파일 실행이나 ZIP 전송을 차단하면 관리자에게 문의해 주세요. 조직 정책을 변경하지 않습니다.
- 설치 실패 시 콘솔 오류와 백업 위치를 확인해 주세요. 실패한 변경은 가능한 범위에서 복원하고 동시에 바뀐 다른 설정은 덮어쓰지 않습니다.

포함하지 않은 것
로그인 정보, 인증 키, 대화 기록, 세션 확인 상태, 전송 대기 원문, 실행 로그, 기존 PC의 모델 목록 캐시는 포함하지 않았습니다.
